# Switch Vision UniFi2MQTT

UniFi2MQTT is the UniFi integration bridge for Switch Vision.

It connects to a UniFi controller, publishes UniFi device and port data to MQTT, and can expose supported entities to Home Assistant through MQTT Discovery.

## Status

Early standalone repository baseline for the Switch Vision v2.1.x development line.

## Goals

- UniFi controller/API connectivity
- MQTT state publishing
- Home Assistant MQTT Discovery
- Switch Vision integration
- Privacy-aware diagnostics and support bundles
- Independent UniFi2MQTT versioning and releases

## Versioning

UniFi2MQTT is versioned independently from Switch Vision.

Current development baseline: `0.1.0-dev`

## Project

Part of the Switch Vision ecosystem.
